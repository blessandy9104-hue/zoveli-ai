Features you can use today

Everything below runs from a local install — no cloud account required.

🔬 Verified mathematics

Solve, differentiate, integrate, linear algebra, number theory, logic, statistics, units — each result confirmed by independent methods with a sealed certificate. A governor routes to algebra, calculus, statistics, logic, units, and discrete specialists that memorize verified proofs and recall them later. Access: CLI /math, or mathcore_compute, math_algebra_solve, math_recall tools.

🧠 Local-first memory

A local SQLite knowledge store with wiki-links, tags, ranked full-text search, and a knowledge graph — mirrored as Markdown files you can open anywhere. CLI: /remember <fact> and /recall <query> work with no model or network. Tools: memory_create_note, memory_search, vault_search, vault_graph.

🎨 Five interface looks, your choice

Daylight, Midnight, Forest, and Sunset are pure-CSS themes that work fully offline; Unicorn adds an animated Unicorn Studio WebGL backdrop (loads only when picked). Smooth Lenis scrolling throughout, served vendored with native-scroll fallback.

💻 17 programming languages

Detection, complexity analysis, formatting, linting, test running, and tooling guides. Access: language_detect, language_analyze, language_format, language_lint, language_run_tests.

🖥️ System & hardware awareness

OS, CPU, memory, disk, GPU, battery, and network insight with budget checks before heavy jobs — all local, zero network calls. Access: sysinfo_snapshot, sysinfo_check.

⚡ Capability awareness

The assistant inventories the tools actually mounted in the host, adapts plans to what's available, and reports gaps. Access: capability_scan, capability_adapt, capability_report.

🛠️ Everyday tools

Code review, doc generation, project health scoring, smart scheduling, and security scanning. Run /tools in the CLI or GET /api/tools for the live list (58 default tools; desktop adds 2 auth tools).

🎭 Personas that fit the moment

Friend, tutor, engineer, and coach — switchable with /persona in the CLI or the persona_switch tool, remembered locally across turns. The tutor guides homework step by step; the engineer shows exact commands and tests before declaring done.

🌐 Grounded web research

Keyless search plus SSRF-guarded page fetching with trusted-source flags (Wikipedia, arXiv, official docs), so current topics get cited instead of guessed. Offline, search simply reports unavailable and answers from memory. Access: web_search, web_fetch.

🔑 Passwordless login

Email one-time codes for any inbox including @proton.me — no passwords, no OAuth middleman. Login is off by default; set ZOVELI_AUTH_REQUIRED=1 to gate the desktop and API, then open /login.

🖥️ Two ways to run

  • CLI — pnpm start, local tools work offline (Windows/macOS/Linux terminals).
  • Desktop — pnpm run desktop, Electron shell around the local server.
