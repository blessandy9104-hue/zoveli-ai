Questions, answered

Does it work without a chat model?

Yes for local tools. Verified math, memory, system insight, scheduling, vault search, and the other local tools run with no model and no network; web research needs network. Chat is an optional adapter — add any key or free local Ollama when you want conversation.

What password do I need?

None for Zoveli. Login is a 6-digit code emailed to you. The only password you'll ever need is your email account's.

What does "verified math" mean?

Every computation runs through independent methods (e.g. symbolic solve + numeric roots + exact substitution). All must agree or the answer is withheld — plus a hash-chained audit certificate. Solved proofs are memorized by specialist agents (algebra, calculus, statistics, logic, units, discrete) and recalled later.

Where is my data?

On your disk: a SQLite store with a Markdown mirror you can open in any editor. Nothing is sent anywhere, nothing trains on it. Backups are encrypted copies you make yourself.

What does it cost to run?

Electricity. No subscription, no credits, no seat fees. Optional model API usage is billed by whoever provides your key, not by us.

Can I change how it looks?

Yes — the web interface ships five looks: Daylight, Midnight, Forest, Sunset, and an animated Unicorn Studio backdrop. Pick from the theme bar; your choice is remembered. Everything except the Unicorn backdrop works fully offline.

Can I use it at work?

It's MIT licensed with a threat model and security policy in the repo. But review both first: local-first means you own backups, updates, and access control for the machine it runs on.

How do I install it?

Ten minutes with the portable runtime, which needs no toolchain: use the one-line installer or an unsigned release .dmg/.exe. Source installs need Node.js 22.16+, Python 3.11+, pnpm, and Git. Later, zoveli update --check reports new releases and zoveli update verifies the SHA-256 before upgrading. See the step-by-step guides.

Why are the binaries unsigned?

Zoveli is independently developed. Paid Apple Developer Program and Microsoft Authenticode certificates would add recurring fees and corporate gatekeepers to every release. Instead, official binaries are unsigned and verified with published checksums and GitHub build-provenance attestations. macOS Gatekeeper and Windows SmartScreen will warn on first launch; the Sovereign Install Guide shows the exact steps.
