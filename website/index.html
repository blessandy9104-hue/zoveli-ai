Why local-first?

Cloud assistants are great — and they run on someone else's computer, bill monthly, and learn from what you type unless you opt out. Zoveli is built on the opposite bet:

PriceFree, runs on your machine, MIT licensed
Your dataStays home — SQLite store you own plus a Markdown mirror, never used for training
OfflineYes for local tools — 58 default tools; web research needs network
MathVerified or withheld — independent methods must agree, sealed certificate; governed specialists memorize proofs
Model choiceAny API key, or free local Ollama (ollama pull qwen3:4b) — swap anytime
LoginOptional passwordless email code; off by default

Use Zoveli when the work is yours: private notes, exact computation, and tools that must work on a plane.

$ curl -fsSL https://raw.githubusercontent.com/blessandy9104-hue/zoveli-ai/main/install/install-zoveli-runtime.sh | bash

Verified mathematics, not guesses

Every computation runs through mathcore: independent methods must agree before any value is released. Real output from this project:

$ mathcore "solve x^2 - 5x + 6 = 0"
VERIFIED  solve x^2 - 5x + 6 = 0 for x
    x = 2; x = 3
    confirmed by: sympy-solve, numeric-polynomial-roots,
                  check:exact-substitution, check:distinct-root-count
    certificate 9c8739cbf1e5ad80

Wrong answers are caught, not repeated: MISMATCH: the claim differs from the verified result.

Local-first by construction

  • SQLite memory, Markdown mirror — your memory is a local database you own, exportable as plain Markdown files.
  • Offline tools — local tools need no API key and no network; web research is explicit and needs connectivity.
  • Optional login — email codes for any inbox including @proton.me; off by default, enable with ZOVELI_AUTH_REQUIRED=1.
  • Capability awareness — the assistant knows what it can do and says when it can't.

Run it on your hardware in minutes

git clone https://github.com/blessandy9104-hue/zoveli-ai.git
cd zoveli-ai
pnpm install && pnpm run build
pnpm start   # CLI — local tools work offline
pnpm run desktop # Desktop shell (Electron, dev mode)
