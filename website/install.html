Download & launch Zoveli AI

Own hardware. Ten minutes. No account needed to start.

0. Portable install (recommended)

No Git, Node, Python, pnpm, or compiler is required. The archive bundles its own runtime and verified-math backend; the installer verifies SHA-256 before extracting.

# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/blessandy9104-hue/zoveli-ai/main/install/install-zoveli-runtime.sh | bash

# Windows PowerShell
irm https://raw.githubusercontent.com/blessandy9104-hue/zoveli-ai/main/install/install-zoveli-runtime.ps1 | iex

Then run the printed zoveli (or zoveli.cmd) path. Re-running the installer stages and preflights the new runtime, creates a verified backup, and rolls back automatically if the upgrade fails. After install, zoveli health reports readiness and zoveli recovery-check proves backup/restore in an isolated temporary vault without touching your real data. CI builds Linux, Windows, and macOS archives and runs a clean-install acceptance test on each; see the acceptance runbook.

Source install (developers)

  • Node.js 22.16+, Python 3.11+, pnpm 11.7.0+, Git
  • Verified math: mathcore ships vendored in ./mathcore (pip install -e ./mathcore)

1. Windows (PowerShell)

winget install OpenJS.NodeJS.LTS Python.Python.3.11 Git.Git
npm install -g pnpm@11.7.0
git clone https://github.com/blessandy9104-hue/zoveli-ai.git
cd zoveli-ai
pip install -e .\mathcore   # vendored: enables verified math
pnpm install
pnpm run build
pnpm test                    # 300+ unit & integration tests, all green
pnpm start                   # launch the CLI assistant

4. Launch it

pnpm start            # CLI — local tools work offline
pnpm run desktop      # Electron shell (dev mode)

In the CLI, try: /math solve x^2 - 5x + 6 = 0 · /remember My spare key is in the blue drawer · /recall blue drawer · /sys · /tools · /help

For free offline chat with no keys, install Ollama and run ollama pull qwen3:4b — Zoveli detects it automatically. Or set any API key (OPENAI_API_KEY, DEEPSEEK_API_KEY, …) for cloud models. No key needed for any local tool.

5. Log in (web UI)

Login is optional. To require it, set ZOVELI_AUTH_REQUIRED=1, open http://127.0.0.1:3080/login, and enter any email address — including @proton.me. Zoveli sends a 6-digit code (no password, no OAuth middleman). Without an SMTP server configured, the code prints to the server console (dev mode).
