Security, by construction

The safest data is data that never leaves your machine.

🔑 No passwords, ever

Zoveli stores zero passwords. Login is a 6-digit code emailed to any inbox, including @proton.me — the only password you'll ever need is your email account's. Codes expire in 10 minutes, allow 5 attempts, and are hashed, never stored.

🏠 Local-first data

  • Your notes live in a SQLite database on your disk (owner-only permissions) with a Markdown mirror you can read anywhere.
  • Sessions are HMAC-signed tokens on your machine — 30-day expiry, HttpOnly cookies.
  • No cloud sync exists. Backups are encrypted copies you make yourself.

🛡️ Guardrails that enforce

  • No shell tool by default — the default surface cannot run arbitrary commands. If you add a custom shell_exec tool, mount the opt-in guard with ZOVELI_PLUGINS=zoveli-guard.
  • Verified math or silence — independent methods must agree; anything else is withheld, never guessed.
  • Secrets are redacted from errors and logs; audit trails are hash-chained and tamper-evident.
  • Local web server binds loopback only, rejects foreign hosts, rate-limits auth and tool routes, and ships hardening headers.

🔍 Open and auditable

MIT licensed and built in the open. Every release runs lint, strict typechecks, 300+ tests, Playwright e2e, Trivy scans, secret scans, and Docker builds. Scan it yourself: the security_scan tool audits any path for secrets and risky patterns.

📣 Report a vulnerability

Do not open public issues for security reports. Email blessandy9104@gmail.com with a description, reproduction steps, and impact. We aim to acknowledge within 48 hours with a fix timeline inside 7 days. See the full security policy.
